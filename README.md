# Forest OS 98 - Wolf Edition

Веб-приложение, имитирующее операционную систему Windows 98 с киберпанк-эстетикой и интегрированным AI ассистентом Nocturne.

## Особенности

- 🐺 **Wolf GPT** - AI ассистент Nocturne с поддержкой чата
- 🎨 **Paint** - графический редактор с выбором цвета и размера кисти
- 💣 **Minesweeper** - сапёр с таймером и счётчиком мин
- 🎮 **Solitaire** - карточная игра
- 🌐 **Forest Explorer** - встроенный браузер
- 🎵 **Forest Player** - музыкальный плеер с визуализацией
- 💻 **WolfSH Terminal** - терминал с поддержкой команд
- 🔐 **Crypto Toolkit** - инструменты для шифрования и хеширования
- 🌐 **Network Tools** - сетевые утилиты (симуляция)
- 📊 **System Monitor** - мониторинг системы
- 📁 **File Manager** - файловый менеджер
- 📝 **Code Editor** - редактор кода
- 📡 **Mesh Network** - симуляция mesh сети Meshtastic

## Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd 98inWeb
```

### 2. Настройка конфигурации

1. Скопируйте файл `config.example.js` в `config.js`:
   ```bash
   cp config.example.js config.js
   ```

2. Откройте `config.js` и укажите ваш API URL:
   ```javascript
   window.FOREST_CONFIG = {
       API_BASE_URL: 'https://your-api-url-here.com',
       MODEL_NAME: 'qwen/qwen3-vl-4b'
   };
   ```

**Важно:** Файл `config.js` находится в `.gitignore` и не будет закоммичен в репозиторий. Это защищает ваши API ключи и настройки.

### 3. Запуск

Просто откройте `forestos.html` в браузере. Для локальной разработки можно использовать любой HTTP сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (http-server)
npx http-server

# PHP
php -S localhost:8000
```

Затем откройте `http://localhost:8000/forestos.html` в браузере.

## Использование

### Первый запуск

1. При первом запуске появится экран входа
2. Введите ваш никнейм (2-20 символов, только буквы, цифры, дефис и подчеркивание)
3. Нажмите "ВОЙТИ"
4. Дождитесь завершения загрузки системы

### Горячие клавиши

- `Alt + Tab` - переключение между открытыми окнами
- `Ctrl + W` - закрыть активное окно
- `Escape` - закрыть активное окно или меню "Пуск"

### Приложения

Все приложения доступны через:
- Двойной клик по иконке на рабочем столе
- Меню "Пуск" → выбор приложения

### Wolf GPT

AI ассистент Nocturne готов ответить на ваши вопросы. История чата сохраняется в cookies и восстанавливается при следующем открытии.

### Сохранение данных

- Позиции окон сохраняются автоматически в `localStorage`
- История чата Wolf GPT сохраняется в cookies (90 дней)
- Настройки фона рабочего стола сохраняются в `localStorage`

## Технические детали

### Технологии

- Чистый HTML/CSS/JavaScript (без фреймворков)
- Canvas API для графики
- Web Audio API для звуков
- LocalStorage и Cookies для хранения данных
- Fetch API для работы с AI

### Браузерная совместимость

- Chrome/Edge (рекомендуется)
- Firefox
- Safari
- Opera

Требуется поддержка ES6+ и современных Web APIs.

## Разработка

### Добавление нового приложения

1. Создайте HTML разметку окна в `forestos.html`
2. Добавьте иконку на рабочий стол и в меню "Пуск"
3. Добавьте обработку в функцию `openWindow()` для инициализации
4. Реализуйте функционал приложения

### Настройка API

API конфигурация загружается из `config.js` перед основным скриптом. Если файл не найден, используются значения по умолчанию.

## Безопасность

- **Никогда не коммитьте `config.js`** - он содержит чувствительные данные
- Используйте `config.example.js` как шаблон для других разработчиков
- API ключи должны храниться только локально
